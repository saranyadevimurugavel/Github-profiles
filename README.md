🚀 GitHub Profile Search App

A simple and responsive web application that allows users to search for any GitHub profile and view their details instantly using the GitHub API.

🌐 Live Demo
👉  https://saranyadevimurugavel.github.io/Github-profiles/

📌 Project Overview

This project fetches real-time data from the GitHub API and displays user profile information such as:

👤 Profile Picture

📛 Username

📝 Bio

👥 Followers & Following

📦 Public Repositories

🔗 Profile Link

It is built using HTML, CSS, and JavaScript with Axios for API requests.

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)

Axios (for API calls)

GitHub REST API

⚙️ How It Works

User enters a GitHub username in the search box.

The app sends a request to the GitHub API.

The API returns user data.

The app dynamically displays the profile information on the page.

🌐 API Used

This project uses the official GitHub REST API:

https://api.github.com/users/{username}
